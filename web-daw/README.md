# Beatforge — browser DAW

Beatforge is a self-contained browser music sketchpad with an FL Studio inspired workflow. It is an original project and does not copy FL Studio's proprietary artwork, name, or source code.

## Features

- 16-step drum sequencer with kick, snare, and hi-hat voices
- Piano roll for adding synthesized notes
- Web Audio playback with adjustable tempo
- Mixer controls, browser autosave, JSON project download, and WAV export
- Responsive layout; no build tools or server required

## Run

Open `index.html` in a modern browser. Click **Play** to start audio; browsers may require a user gesture before sound can play.

This is an early sketchpad, not a full professional DAW. It does not currently support plugins, multitrack audio recording, or MIDI import.
